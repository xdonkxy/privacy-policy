Datenschutzerklärung

Stand: 24. September 2026

1. Verantwortlicher

Verantwortlicher für diesen Discord-Bot ist:

Discord: Eselein

2. Zweck des Discord-Bots

Dieser Discord-Bot dient dazu, Statistiken von Spielern des Minecraft-Servers The Hive abzufragen und innerhalb von Discord anzuzeigen.

Der Bot ermöglicht es Nutzern, öffentlich verfügbare Spielerstatistiken über entsprechende Bot-Befehle abzufragen.

3. Welche Daten werden verarbeitet?

Bei der Nutzung des Bots können technisch folgende Informationen verarbeitet werden:

  • Discord-Benutzer-ID
  • Discord-Server-ID
  • Discord-Kanal-ID
  • der vom Nutzer eingegebene Minecraft-/The-Hive-Spielername
  • öffentlich verfügbare The-Hive-Spielerstatistiken

Diese Informationen werden verarbeitet, soweit dies für die Ausführung der jeweiligen Bot-Funktion erforderlich ist.

4. The-Hive-API

Der Bot verwendet eine API bzw. entsprechende Datenschnittstellen von The Hive, um Spielerstatistiken abzurufen.

Dabei werden die für die jeweilige Abfrage erforderlichen Informationen an die entsprechende API übermittelt. Die vom Bot angezeigten Spielerstatistiken stammen aus den über diese Schnittstelle verfügbaren Daten.

5. Speicherung

Der Bot ist grundsätzlich darauf ausgelegt, die für eine Statistikabfrage benötigten Daten nur zur Verarbeitung der jeweiligen Anfrage zu verwenden.

Sofern keine zusätzliche Speicherfunktion aktiviert ist, werden die über eine einzelne Statistikabfrage erhaltenen Daten nicht dauerhaft durch den Bot gespeichert.

Technische Protokolle können abhängig vom verwendeten Hosting- oder Serveranbieter entstehen.

6. Discord

Der Bot funktioniert innerhalb der Plattform Discord. Discord selbst kann bei der Nutzung des Dienstes personenbezogene Daten verarbeiten.

Weitere Informationen findest du in der Datenschutzerklärung von Discord .

Der Betreiber verkauft oder vermietet keine über den Bot verarbeiteten Daten zu Werbezwecken.

Für den technischen Betrieb können externe Dienste, beispielsweise Hosting- oder API-Anbieter, eingesetzt werden. Dabei können technisch erforderliche Daten an diese Dienste übertragen werden.
